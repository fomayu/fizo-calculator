# Ориентир · ФИЗО

Адаптивный статический калькулятор для военнослужащих ВС РФ по контракту. Фиолетово-розовое оформление с военными акцентами, без сбора персональных сведений и аналитики.

## Автоматический расчёт

Пол, возраст, категория → набор и количество упражнений → введённые результаты → баллы → проверка минимумов → оценка и квалификационный уровень → возможная ежемесячная надбавка. Все50 тарифных разрядов и воинские звания. Цели до следующего уровня: конкретный результат в каждом подходящем упражнении при неизменных остальных, разница в возможной выплате. Компактная итоговая карточка для скриншота.

Баллы извлечены из таблиц приложения5 полного текста приказа МО230 (ред.08.12.2025);111 таблиц с возрастными и весовыми вариантами. Пороги приложения6 сверены с опубликованным НФП. Между строками используется менее выгодный норматив; ниже последнего результата0, максимум100. Минуты:секунды хранятся в секундах, не десятичной дробью. Минимум проверяется в каждом упражнении. Физические качества и количество ОФУ/СФУ проверяются по пп87–92. Для специальных упражнений техника и выбор КПК проверяются комиссией.

## Оклады

База2019 приказа727, приложение3:2020×1.03 (939),2021×1.037 (772),2022×1.04 (719),2023×1.105 (1046),2024 без индексации,2025×1.076 (464 в редакции1390). Каждый шаг — округление каждого оклада вверх до рубля. Первоначальные4.5%2025 не добавляются. Последним шагом условные×1.04 с октября2026 — допущение пользователя, не сообщение об официальном повышении. Второй уровень15%,первый30%,высший70% только от оклада по должности. Оклад по званию в базу этой выплаты не входит.

## Ограничения

Спортивный разряд — справочно: все персональные условия выплаты по430дсп из открытого первичного текста подтвердить не удалось. Спортивная выплата не складывается с ФИЗО и не включена в сумму. Индивидуальные КПК дляIIIа/IIIб группы здоровья, поправки за высоту и Крайний Север не реализованы. Сумма до удержаний, без районных коэффициентов. Результат калькулятора не заменяет проверку техники и приказ о назначении выплаты.

## Проверки и запуск

Раздайте dist любым статическимHTTP-сервером. Нет зависимостей и сборки. node test.mjs — финансовые расчёты; node auto-test.mjs — каждое значение всех таблиц, пол/возраст/категории, границы оценок, минимумы, парсинг времени, варианты целей. Данные формы остаются в странице, без передачи на сервер. Публикация на нейтральном адресе Sites, имя GitHub в адресе сайта не используется.
