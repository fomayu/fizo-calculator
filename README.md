# Ориентир · ФИЗО

Статический адаптивный калькулятор в тёмном фиолетово-розовом оформлении с военными акцентами. Не собирает персональные сведения, не содержит аналитики, токенов и внешних зависимостей. Данные формы не отправляются на сервер и не сохраняются после перезагрузки.

## Реализовано

Пол, возраст, категория, 2–5 упражнений, результаты, ручной ввод баллов, сумма; все 50 тарифных разрядов; звания; расчёт возможной надбавки по уровню из ведомости; разница до вручную заданного порога и разница в выплате; карточка для скриншота. Спорт — только справочно.

## Ограничения

Перевод результатов в баллы и автоматическое присвоение оценки/уровня отключены до полной независимой сверки таблиц и всех правил допустимых сочетаний упражнений. Результаты не выдумываются. Список упражнений основан на открытом исходном калькуляторе, не определяет допустимость выбора для конкретной должности. Не все нормативные ограничения реализованы. Уровень и целевой порог пользователь берёт из официальной ведомости/НФП. Число повторений до следующего уровня пока не рассчитывается.

Спортивные достижения не увеличивают сумму: актуальные персональные условия и запрет суммирования по №430дсп не удалось полностью подтвердить открытым первичным текстом. Не предполагается автоматическое суммирование ФИЗО и спорта.

## Денежный расчёт

Оклад из приложения №3 приказа №727 (база2019) последовательно увеличивается: 2020×1.03 (ПП939),2021×1.037 (ПП772),2022×1.04 (ПП719),2023×1.105 (ПП1046),2024 без повышения,2025×1.076 (ПП464 в редакции1390). Каждый оклад округляется вверх до целого рубля на каждом шаге. Первоначальные4.5%2025 не применяются дополнительно.

Последним шагом всегда условные×1.04 с округлением вверх до рубля — личное допущение, не подтверждение официальной индексации2026. Шкала расчёта возможной выплаты: второй уровень15%, первый30%, высший70% только от оклада по должности; третий уровень0%. Сумма до удержаний, без районных коэффициентов. Оклад по званию показан отдельно, в базу этой выплаты не входит. Право на выплату определяется документами и приказом командира; интерфейс его не устанавливает.

## Запуск и проверки

Раздайте каталог `dist` любым статическим HTTP-сервером. Сборка и установка пакетов не требуются. Тесты: `node test.mjs`. На GitHub Pages публикуется каталог `dist`, но по пожеланию пользователя адрес с именем аккаунта не используется. Альтернативный нейтральный хостинг настраивается отдельно.
